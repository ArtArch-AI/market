# Chinese Short-Drama Canvas

## Purpose

Turn a 15-120 second vertical-drama idea into independently renderable clips with
explicit character, environment, storyboard, continuity, and assembly contracts.

## Dramatic contract

Build the episode around:

`viewing promise -> character pressure -> power or information shift -> reversal or consequence -> next hook`

Every episode must change a decision, relationship, public fact, or consequence.
Atmosphere alone is not an episode beat.

## Topology

`episode brief -> character/environment masters -> chronological storyboard -> atomic clips -> ordered stack`

For consistency-sensitive or longer productions, expand the middle into the
[asset-first progressive storyboard pattern](progressive-storyboard-video.md):

`episode brief -> canonical assets -> segment sketch boards -> rendered segment boards -> clean handoffs -> atomic clips -> ordered stack`

Approve the sketch before rendering and the rendered board before video. Keep
each segment's dialogue, sound, opening state, and endpoint aligned across all
three stages.

Recommended groups:

1. `01 Story contract`
2. `02 Canonical assets`
3. `03 Storyboard`
4. `04 Atomic clips`
5. `05 Delivery`

## Atomic clip contract

- Use one continuous camera, one dramatic event, and one main speaker per clip.
- Keep dialogue physically compatible with the duration.
- Repeat exact dialogue in the storyboard and clip prompt.
- End each clip with a visible state that the next clip can inherit verbatim.
- Split hidden edits, reaction shots, and later reveals into separate clips.

## Maintained example

The example is a 15-second, 9:16 workplace reversal: an adult product planner is
publicly denied credit, quietly reveals a timestamped approval record, and ends
with the supervisor realizing the evidence is already on screen.

The storyboard has three ordered 5-second panels. Each video node names its panel,
opening state, visible action, exact line, and endpoint. The delivery node receives
the three video outputs in order.

## Acceptance

Reject clips that replay a completed beat, paraphrase dialogue, move a prop between
hands without cause, change wardrobe version, cross screen direction accidentally,
or leave the next clip without an observable starting state.
